# ADR (Architecture Decision Records)

本目录记录本项目关键架构决策。每个决策一个 Markdown 文件。

## 命名约定
`ADR-NNN-title-in-kebab-case.md`

## 模板

```markdown
# ADR-001: 决策标题

- **Status**: Proposed / Accepted / Deprecated / Superseded
- **Date**: YYYY-MM-DD
- **Deciders**: <名单>

## Context
<背景与问题>

## Decision
<决策>

## Consequences
<后果，含正面和负面>

## Alternatives Considered
<替代方案与放弃理由>
```
